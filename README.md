# CollegePro — College Management System

**Task ID:** WD-COL-001  
**Student Code:** DAS-COL-001  
**Company:** Data Alcott Systems

CollegePro is a responsive, frontend-only college administration dashboard built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Dashboard with college statistics, enrollment overview and attendance summary
- Student management: enroll, search, filter, edit and delete
- Faculty management: add, search, edit and delete
- Course management with faculty assignment and credits
- Department overview and department head editing
- Attendance tracking by date and student
- Weekly timetable with add-class interaction
- Reports and department analytics with CSV export
- Notice board and campus events
- Dark mode and responsive sidebar/mobile layout
- Browser localStorage for demo persistence

## Run locally
Open `index.html` in a browser, or use VS Code Live Server. No database, package installation or build step is required.

## Demo limitations
This is a frontend educational simulation. Login is not real authentication; records are stored locally in the current browser. There is no backend, database, multi-user synchronization or secure role management. Dashboard figures and sample records are illustrative.

## Technologies
HTML5 · CSS3 · JavaScript · localStorage
